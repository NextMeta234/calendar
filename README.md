# Next Meta Calendar

The official repository for the calendar application hosted at `calendar.next-meta.com`.

## Overview

A lightweight, single-page web calendar designed for simple and fast schedule viewing.

- **Live Site**: [https://calendar.next-meta.com](https://calendar.next-meta.com)

- CSS3
- JavaScript

## Local Setup

No installation or dependencies required.

Open the application
